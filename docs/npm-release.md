# npm release

The canonical release guide is [Releasing to npm](../site/content/docs/release.md),
published at [the project site](https://jj-marinho.github.io/duckposting/docs/release).

Nothing has been published to npm. The root remains private; Pages and CI only
build the local release candidate. Keep the package name `duckposting` and use
adapter subpaths, rather than publishing separate core/integration packages.
